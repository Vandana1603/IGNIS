# IGNIS 2.1 — Official NASA resource map

## Scientific evidence versus scientific context

**Only original fields from the locally curated NASA PSI BASS-II (PSI-25) and FLEX (PSI-69) test tables are used as experimental measurements in IGNIS.** Search, charts, audit and SI responses operate on those imported records. The source links below add reference context; opening a NASA webpage is not the same as importing a scientific record. SHA-256 consistency tests establish integrity of local curated files, **not independent confirmation that manual transcription exactly matches the latest NASA original tables**.

### Experimental data — used in the implemented backend
- [NASA PSI Combustion Search](https://psi.nasa.gov/physci/repo/search?q=combustion) — research discovery portal; searchable but not a guaranteed public machine-readable real-time API.
- [NASA PSI-25 BASS-II](https://psi.nasa.gov/physci/repo/data/investigations/PSI-25) — source investigation for the manually curated B1, B3 and B4 test table rows (DOI: 10.60555/4qc4-de67).
- [NASA PSI-69 FLEX](https://psi.nasa.gov/physci/repo/data/investigations/PSI-69) — source investigation for the manually curated 20CAL08, 20CAL10 and 20CAL12 rows (DOI: 10.60555/mbq8-0451).

### Scientific/background explanation — not imported as measured data
- [NASA Combustion Science](https://www.nasa.gov/glenn/glenn-expertise-space-exploration/physical-sciences-program/combustion-science/) — research programs including BASS and FLEX, ISS facilities including MDCA and CIR.
- [A Researcher's Guide to ISS Combustion Science](https://www.nasa.gov/missions/station/a-researchers-guide-to-combustion-science/) — research overview.
- [NASA ScienceCasts, The Power of Studying Combustion on the ISS](https://www.youtube.com/watch?v=W1oXykoz9zg) — NASA explanatory video linked by the challenge.

### Historical context — explicitly not experimental records
- [Apollo 1](https://sma.nasa.gov/sma-disciplines/accllp/apollo-1) — fatal prelaunch cabin fire, lessons learned.
- [Apollo 13](https://sma.nasa.gov/sma-disciplines/accllp/apollo-13) — oxygen tank explosion, not an open-flame PSI combustion experiment.
- [1997 Mir space-station fire](https://www.nasa.gov/history/25-years-ago-fire-aboard-space-station-mir/) — oxygen-generator fire history.

### Technology transfer / Earth applications — not experimental records
- [Fireman's Air Tanks](https://spinoff.nasa.gov/node/9582) — breathing equipment adaptation.
- [Fire Detector](https://spinoff.nasa.gov/node/9407) — smoke-detection research / transfer.
- [New Technology for the Fire Attire](https://spinoff.nasa.gov/node/9918) — protective gear technology transfer.

## Live research sync: what is and is not live

The `/v8/sync/check` endpoint makes on-demand HTTPS requests to allowlisted NASA PSI investigation pages; it can report source reachability and detect discoverable downloadable links in retrieved HTML. It **does not** provide live International Space Station sensor telemetry or guarantee that all NASA PSI records are exposed through machine-readable links. The `/v8/sync/stage` route downloads explicitly selected discovered files to a separate staging area. No staged data become part of charts or SI answers without a validated, source-specific import step.

## Laboratory schematics

The SVG views are original, annotated *illustrative* diagrams, not engineering CAD drawings, experiment footage, simulated scientific outcomes, or scaled flame photographs. BASS-II is represented as a flow-duct experiment associated with the Microgravity Science Glovebox; FLEX is represented as a droplet-combustion apparatus associated with the Multi-user Droplet Combustion Apparatus and Combustion Integrated Rack. Scientific measurements displayed beside drawings are fetched from the imported backend data, never generated by the drawings.
