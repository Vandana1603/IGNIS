# IGNIS — live demo plan (~150 seconds)

**00:00–00:20 — The challenge**

"NASA records microgravity combustion experiments, but measurements from different apparatus cannot be interpreted as if they were one uniform dataset. IGNIS connects the experimental setup to the original evidence."

Home screen: "See beyond the flame." Point to imported-record count and documented scope. No invented safety-performance metrics.

**00:20–00:45 — Interactive laboratory (creativity and relevance)**

Select FLEX and click the fuel, ambient environment, and observations. Inspect a real test (e.g. 20CAL10). The illustration is schematic; original recorded values are shown separately with source-field links.

**00:45–01:15 — Guided mission: observation**

Open Start Research Mission, go to Step 2 and show its recorded burn-time field and the Evidence Passport link. Explain that it comes from an imported NASA PSI-69 table row, not generated output.

**01:15–01:45 — Comparability Guard (validity)**

On Step 3, compare the recorded FLEX tests. Cite original condition differences and explain that differing burn times do not prove causation. Show a cross-investigation comparison only if time permits.

**01:45–02:05 — Live NASA Repository Check (impact and credibility)**

Open `/sync`, click the actual on-demand source check. If network access is available, display response timestamps. If unavailable, show the honest failure state and explain the locally verified catalog remains usable. Do not promise newly imported measurements or ISS telemetry.

**02:05–02:25 — Scientific abstention (validity)**

At Step 4 ask: "Which material is safest for a spacecraft?" The deterministic SI should refuse the unsupported operational claim. This is a deliberate evidence-based safeguard.

**02:25–02:30 — Close**

"IGNIS turns microgravity flame research into something navigable, traceable and harder to misuse." Point to the source library and NASA attribution.

## Avoid during the demo

- Implying six curated rows equal NASA's full repository.
- Presenting NASA historical incidents or Spinoffs as numerical combustion data.
- Calling on-demand repository checks live experiment telemetry.
- Labeling source-website reachability as a new measurement.
- Claiming the diagram predicts real flame shapes, or that comparison proves causality.
